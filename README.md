# Flowgorithm Hesap Makinesi

Bu benim Flowgorithm ile yaptığım **ilk proje**.  
Kullanıcıdan iki sayı ve işlem türü (+, -, *, /) alıyor, sonucu ekrana yazdırıyor.

### Özellikler
- Toplama  
- Çıkarma  
- Çarpma  
- Bölme  
- Geçersiz işlem kontrolü  

### Öğrendiklerim
- Değişken tanımlama  
- Kullanıcıdan veri alma  
- Hesaplama yapma  
- Sonucu gösterme  
- Karar yapıları  

### Not
Bu proje Flowgorithm `.fprg` dosyasıdır.  
GitHub üzerinde XML kodu gibi görünür ama Flowgorithm ile açıldığında **akış diyagramı** olarak çalışır.
